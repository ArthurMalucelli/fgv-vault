2. Seleção de coluna

df["c"]              # Series (1D)
df[["c1","c2"]]      # DataFrame (várias, ordem da lista)
df[["c"]]            # DataFrame com 1 col (≠ Series)

1 colchete vira Series, 2 colchetes viram DataFrame. Pra reordenar colunas, usa 2.

DataFrame é a tabela inteira (2D, várias colunas). Series é uma coluna sozinha (1D). Series tem métodos de coluna (mean, str, value_counts). DataFrame não. 99% das operações tu quer Series (1 colchete).

3. Filtro lógico (linha)

cond = df["Produto"] == "GASOLINA"   # Series booleana
df[cond]                              # filtra

df[df["Produto"] == "GASOLINA"]
df[df["Valor de Venda"] > 6]
df[df["Bandeira"] != "BRANCA"]
df[df["Bandeira"].isin(["VIBRA","RAIZEN"])]
len(df[df["Produto"]=="GASOLINA"])    # quantas

Filtro é sempre 2 etapas: cria Series booleana (True/False por linha) com a condição, aplica dentro do df[...]. Pandas vê booleana ali e fica só com linhas True. Ops: == != > < >= <= e .isin([...]) pra "está na lista".

4. AND / OR / NOT

# NUNCA and/or/not. Sempre & | ~
df[(df["Produto"]=="GASOLINA") & (df["Valor de Venda"]>6)]
df[(df["Bandeira"]=="VIBRA") | (df["Bandeira"]=="RAIZEN")]
df[~(df["Bandeira"]=="BRANCA")]

# Recomendado (cada cond como variável):
c1 = df["Produto"]=="GASOLINA"
c2 = df["Valor de Venda"]>6
df[c1 & c2]

Cada condição entre parênteses. Esquecer é erro #1.

Pandas tem operadores próprios pra booleanas: & (E), | (OU), ~ (NÃO). NUNCA usa and/or/not de Python puro. Cada condição entre parênteses, ou a precedência quebra silenciosamente.

6. .str (strings na coluna)

df["c"].str.upper() / .lower() / .title() / .strip()
df["c"].str.len()                    # tamanho
df["c"].str.contains("POSTO")        # booleana (filtro!)
df["c"].str.startswith("AUTO") / .endswith("LTDA")
df["c"].str.replace("LTDA","")       # SUBSTRING
df["c"].str[0]  .str[-3:]  .str[6:10]      # slice
df["c"].str.split()                  # vira lista
df["c"].str.split(expand=True)       # vira DF
df["c"].str.split().str[-1]          # último elemento

df["c"].str.upper().str.replace("LTDA","").str.strip()  # encadeia

Sem .str: 'Series' object has no 'upper'. Sempre .str antes.

.str é a ponte entre Series e métodos de string Python. Sem ela, df["c"].upper() falha porque Series não tem upper. Com .str, o método é aplicado em cada string da coluna, retorna Series nova.

7. replace vs .str.replace

FormaCompara
col.replace("SP","BA")valor inteiro
col.str.replace("SP","BA")substring no texto
df["Estado"] = df["Estado"].replace("SP","Sao Paulo")
df["Bandeira"] = df["Bandeira"].replace({"BRANCA":"SEM","VIBRA":"BR"})

replace compara o valor INTEIRO (célula tem que ser exatamente "SP"). .str.replace troca SUBSTRING dentro do texto (parcial). Dicionário {velho: novo} troca vários valores de uma vez.

8. Criar / atualizar coluna

df["nova"]    = df["a"] + df["b"]      # cria à direita
df["a"]       = df["a"] * 1.1          # substitui
df["Pais"]    = "Brasil"               # constante
df["Cid_U"]   = df["Municipio"].str.upper()

Pegadinha mortal: df = df["c"].str.lower() DESTRÓI o DF (vira Series). Esquerda tem que ser df["c"], NUNCA df.

Pra criar OU atualizar coluna, esquerda é df["c"]. Se a coluna já existe, substitui; se não, cria à direita da última. Mesma sintaxe pros dois casos.

12. Ordenação / duplicatas / nulos

df.sort_values("c", ascending=False)   # NÃO persiste sozinho
df = df.sort_values("c")               # PERSISTE
df.drop_duplicates(subset=["CNPJ"])

sort_values retorna DataFrame ordenado mas NÃO modifica o original. Reatribui pra persistir. drop_duplicates com subset remove linhas duplicadas considerando só essa(s) coluna(s).

13. groupby (operação-chave)

# df.groupby(CRITÉRIO)[COLUNA].FUNÇÃO()
df.groupby("Bandeira")["Valor de Venda"].mean()
df.groupby("Produto")["Valor de Venda"].max()

# Filtro + groupby:

Funções: mean, sum, median, min, max, std, size (linhas), count (não-nulos), nunique, first, last.

groupby DIVIDE o DataFrame em pedaços por valor da coluna critério (split), APLICA a função em cada pedaço (apply), JUNTA tudo numa Series (combine). Equivale a tabela dinâmica do Excel. CRITÉRIO entre (), COLUNA DE VALOR entre [].

groupby com várias estatísticas de uma vez. Lista pra mesma coluna com múltiplas funções, dicionário pra coluna+função, combinação dos dois pra cenário cheio.

15. Ranking, top N, idxmax

df.groupby("B")["v"].mean().sort_values(ascending=False)
df.groupby("Municipio")["v"].mean().sort_values(ascending=False).head(5)

# RÓTULO do maior/menor (não o valor):
df.groupby("Municipio")["v"].mean().idxmax()  # nome
df.groupby("Municipio")["v"].mean().max()     # valor

Pra ranking, encadeia .sort_values(ascending=False) depois do groupby. Pra pegar o NOME do município/bandeira com maior média, usa .idxmax() (rótulo). Pra pegar o VALOR da média, usa .max().

pd.merge(L, R, on="k", how="inner")

pd.merge(L, R, left_on="A", right_on="B", how="left")
L.merge(R, on="k")                              # método
howLinhas

outerunião, falta = NaN

Chave incompleta → cartesiano. Se shape exploder, falta col no on.

Junta dois DataFrames por uma chave em comum (coluna que existe nos dois). inner mantém só chaves presentes nos dois, mas ADICIONA todas as colunas do segundo DataFrame que enriquecem as linhas. Se a chave real precisa de várias colunas, passa lista, senão vira produto cartesiano.

20. Regras-mãe (decora estas)

  • = atribui, == compara. Errar é clássico.
  • Estatística sempre em coluna: df["c"].mean(), não df.mean().
  • Atualizar coluna: esquerda é df["c"], nunca só df.
  • Booleano: & | ~, cada cond entre parênteses.
  • loc fim inclusivo, iloc fim exclusivo.
  • Métodos com (); atributos sem (shape, columns, dtypes).
  • sort_values não persiste sozinho. Reatribui.
  • Sempre .str antes de função de string.
  • copy() ao criar subset que vai ser modificado.
  • Chave de merge incompleta → cartesiano. Confere shape depois.
