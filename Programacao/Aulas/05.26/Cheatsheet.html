14. groupby (a operação mais importante)

# Estrutura: df.groupby(CRITÉRIO)[COLUNA].FUNÇÃO()
df.groupby("Bandeira")["Valor de Venda"].mean()
df.groupby("Produto")["Valor de Venda"].max()
df.groupby("Municipio")["CNPJ"].nunique()    # postos distintos por cidade
df.groupby("Bandeira").size()                # qtd linhas por grupo

# Múltiplos critérios (lista):
df.groupby(["Municipio","Produto"])["Valor de Venda"].mean()

# Critério como coluna em vez de índice:
df.groupby("Bandeira", as_index=False)["Valor de Venda"].mean()

# Filtro + groupby:
df[df["Produto"]=="GASOLINA"].groupby("Municipio")["Valor de Venda"].mean()
FunçãoFaz
.mean()média
.sum() .median()soma, mediana
.min() .max() .std()extremos, dispersão
.size()qtd linhas no grupo
.count()não-nulos numa coluna
.nunique()distintos numa coluna
.first() .last()primeiro/último valor

15. agg (várias estatísticas)

# Várias funções pra mesma coluna:
df.groupby("Bandeira")["Valor de Venda"].agg(["mean","min","max","std"])

# Diferentes funções pra diferentes colunas:
df.groupby("Bandeira").agg({
    "Valor de Venda": "mean",
    "CNPJ": "nunique",
})

# Combinado:
df.groupby("Bandeira").agg({
    "Valor de Venda": ["mean","min","max"],
    "CNPJ": "nunique",
})

20. Caso da prova: postos + distrib

# 1. Cria chave Mes em postos (formato YYYY-MM):
postos["Mes"] = (postos["Data da Coleta"].str[6:10] + "-"
                 + postos["Data da Coleta"].str[3:5])

# 2. Junta pela chave tripla:
juntos = pd.merge(
    postos, distrib,
    on=["Municipio","Produto","Mes"],
    how="inner",
)

# 3. Calcula margem:
juntos["margem"] = juntos["Valor de Venda"] - juntos["Preco_Distribuicao"]

# 4. Margem média por bandeira (ranking):
juntos.groupby("Bandeira")["margem"].mean().sort_values(ascending=False)

25. Atalhos mentais (regras-mãe)

  • = vs ==: um atribui, dois compara. Errar é clássico.
  • Estatística sempre em coluna: df["c"].mean(), não df.mean().
  • Reordenar / atualizar coluna: esquerda é df["c"], não df.
  • Booleanos: & | ~, cada cond entre parênteses. Nunca and/or/not.
  • Slice loc: fim inclusivo. iloc: fim exclusivo.
  • Métodos com (), atributos sem. shape sem, head() com.
  • sort_values não persiste sozinho. Reatribui.
  • Sempre .str antes de função de string.
