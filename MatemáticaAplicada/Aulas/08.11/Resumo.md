# Resumo — Propriedades de limites (sessão de exercícios)

| Item | O que é |
|---|---|
| Constante multiplicando | A constante sai do [[Limite (cálculo)|limite]]: `lim k·f(x) = k · lim f(x)` |
| Limite de composta (raiz, potência) | O limite passa para dentro: `lim √f(x) = √(lim f(x))`; calcula o limite de dentro e aplica a operação no resultado |
| Quociente 0/0 | [[Forma indeterminada]]: substituiu e deu 0 em cima E embaixo → fatorar ou racionalizar |
| Racionalização | Quando a indeterminação envolve raiz, multiplica pelo conjugado ([[Racionalização por conjugado]]) |
| Regra do delta ([[Bhaskara]]) | Δ > 0: duas raízes reais distintas · Δ = 0: raiz dupla · Δ < 0: sem raiz real |

## Fórmulas

```
lim k·f(x) = k · lim f(x)
lim √f(x) = √( lim f(x) )
Δ > 0 → duas raízes ; Δ = 0 → raiz dupla ; Δ < 0 → sem raiz real
ax² + bx + c = a(x − x₁)(x − x₂)   (forma fatorada)
```

## Pegadinhas / pontos de prova

- 0/0 é indeterminação e exige manipulação (fatorar/racionalizar). Denominador zero com numerador não-zero NÃO é o mesmo caso.
- Antes de fatorar quadrática, checar o delta: se Δ < 0 não existe fatoração real.
- Resultado exato (fração, exponencial) pode ficar indicado; decimal só se pedirem.
