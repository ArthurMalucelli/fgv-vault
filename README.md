## Organização

- As matérias ativas ficam na raiz; as aulas seguem o padrão `<Materia>/Aulas/MM.DD/`.
- `Vault/` reúne materiais de apoio, conceitos, templates e o arquivo do semestre anterior.
- [Tasks.md](Tasks.md) centraliza as tarefas.
- [INSTRUCTIONS.md](INSTRUCTIONS.md) descreve as convenções de manutenção do vault.

## Como consultar

Leia os arquivos Markdown diretamente no GitHub ou clone o repositório e abra a pasta como vault no Obsidian:

```bash
git clone https://github.com/ArthurMalucelli/fgv-vault.git
```

O repositório contém também PDFs e outros materiais; o download é maior que o de um projeto composto apenas por texto. Para acrescentar conteúdo, mantenha a estrutura por disciplina e use a data da aula correspondente.
