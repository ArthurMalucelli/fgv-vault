# Adiantamento de Cliente

## Definição

Dinheiro recebido do cliente antes de entregar o produto ou prestar o serviço. Não é receita: a empresa ainda deve a entrega, então é passivo (uma obrigação de entregar, ou de devolver o dinheiro). Vira receita na [[DRE]] só quando a entrega acontece, pelo [[Regime de Competência]]. Caixa entra antes do fato. É o espelho de contas a receber (fato antes do caixa).

## Fórmula / aplicação

```
Cliente paga 800 em M1 por marmitas entregues em M2:
M1: caixa +800 | adiantamento de cliente +800 (passivo)   -> receita zero, FCO +800
M2: adiantamento -800 | receita 800                       -> receita 800, FCO zero

Armadilha: no fim de M1 o caixa tem 800 a mais, mas esse dinheiro "tem dono".
Retirar como se fosse lucro é distribuir dinheiro do cliente.
```
