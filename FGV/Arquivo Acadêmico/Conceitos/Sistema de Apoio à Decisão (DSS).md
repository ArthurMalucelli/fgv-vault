# Sistema de Apoio à Decisão (DSS)

## Definição

Decision Support System: sistema de informação voltado para a estratégia, no nível de apoio à decisão gerencial. Reúne toda a informação disponível na empresa e coloca à disposição do grupo gerencial: gráficos, indicadores, KPIs. Hoje incorpora agentes de IA (AI Agent Systems) que dão suporte a departamentos inteiros.
