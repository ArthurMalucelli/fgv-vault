# Ativo Não Circulante

## Definição

Parcela do ativo de longo prazo, onde fica o imobilizado. Indústria costuma ter mais peso aqui. Na Vivara deu 35% do ativo total, baixo pra quem fabrica joia, o que foi ponto de discussão em aula.

## Fórmula / aplicação

```
% aplicado no longo prazo = Ativo não circulante / Ativo total
```
