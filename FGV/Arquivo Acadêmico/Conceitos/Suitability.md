# Suitability

## Definição

Análise de Perfil do Investidor (API). Obrigação do distribuidor de verificar se o produto recomendado é adequado ao cliente, considerando objetivos, situação financeira e conhecimento. Regulada pela [[CVM]] (Resolução CVM 30).

## Três dimensões avaliadas

| Dimensão | O que avalia |
|---|---|
| Objetivo | Pra que o cliente investe (preservar, crescer, aposentar) |
| Situação financeira | Patrimônio, renda, comprometimento, horizonte |
| Conhecimento | Experiência prévia, formação, familiaridade com produtos |

## Quando aplicar

- Antes da primeira recomendação
- Renovação obrigatória a cada 24 meses
- Quando o cliente solicita mudança no perfil
- Quando há alteração relevante na situação do cliente

## Dispensas

API NÃO é exigida quando:
- Cliente é Investidor Qualificado ou Profissional (com declaração)
- Operação é por iniciativa própria do cliente, sem recomendação
- Produto é Renda Fixa Simples (CDB, LCI, LCA simples sem cláusulas exóticas)
- Pessoa jurídica de direito público

## Pegadinhas

- Suitability é dever do **distribuidor**, não do gestor
- Recomendar produto inadequado é infração mesmo se o cliente lucrar
- Cliente pode operar contra o perfil, mas precisa assinar termo de ciência
- API não dispensa [[KYC]], são processos complementares
