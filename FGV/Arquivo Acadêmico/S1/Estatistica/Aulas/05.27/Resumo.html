1. O problema fundamental

Estatística inferencial existe pra resolver um problema simples: você quer saber a média de uma característica de uma população enorme (todos os adultos brasileiros, todos os clientes de um banco, todos os componentes que saem de uma fábrica), mas medir todo mundo é impraticável. Solução: você mede só uma amostra de n pessoas, calcula a média amostral X̄, e usa X̄ pra estimar a média populacional verdadeira μ.

O problema é que X̄ tem erro. Se você refizesse a pesquisa com outra amostra de n pessoas, daria um X̄ diferente. Então em vez de dizer "μ ≈ X̄" (chamado estimativa por ponto, frágil), você dá uma faixa de valores plausíveis: "μ está entre LI e LS com γ% de confiança". Essa faixa é o intervalo de confiança (IC).

O IC tem três peças:

  • O centro, que é X̄
  • A margem de erro E, que define a largura
  • O nível de confiança γ (tipicamente 95%, 90% ou 99%)

A fórmula geral é simplesmente IC = X̄ ± E. Toda a discussão sobre IC é sobre como calcular E corretamente em cada cenário.

A diferença entre as três fórmulas de IC (σ conhecido, σ desconhecido, proporção) é só o cálculo de E. O resto é igual: estimativa ± E.

2. Distribuição normal, refresher rápido

Distribuição é simplesmente como os valores se espalham. A normal tem formato de sino simétrico, descrita por dois parâmetros: a média μ (onde fica o pico) e o desvio padrão σ (largura do sino). Quanto maior σ, mais espalhada a distribuição.

A regra empírica: ~68% dos dados ficam dentro de μ ± 1σ, ~95% dentro de μ ± 2σ (mais precisamente 1,96σ), e ~99,7% dentro de μ ± 3σ. É daqui que sai o famoso "Z = 1,96 cobre 95%".

A normal padrão é a normal com μ = 0 e σ = 1, geralmente chamada de Z. Qualquer X normal pode ser convertido em Z subtraindo a média e dividindo pelo desvio:

Z = (X − μ) / σ

Isso permite usar uma tabela única (de Z) pra resolver qualquer problema com normal, qualquer que seja μ e σ.

P(X < x) numa normal qualquer = DIST.NORM.N(x ; μ ; σ ; 1)
P(Z < z) na normal padrão = DIST.NORM.P.N(z ; 1)

3. Distribuição amostral da média

Aqui está a peça mais importante pra entender IC. Imagina que você refizesse a pesquisa muitas vezes (universos paralelos), sempre coletando uma nova amostra de n pessoas e calculando o X̄ de cada uma. Cada amostra daria um X̄ diferente. A coleção desses infinitos X̄ tem uma distribuição própria, chamada distribuição amostral da média.

Essa distribuição tem três propriedades fundamentais:

  • Centro: μ (a mesma média da população). Os X̄ se distribuem ao redor de μ.
  • Desvio padrão: σ/√n, chamado erro padrão. É o desvio dos X̄, não dos X individuais.
  • Formato: normal, sob certas condições (ver TLC abaixo).

O ponto crucial é que σ/√n < σ. A dispersão das médias amostrais é menor que a dispersão dos valores individuais. Faz sentido: amostras maiores produzem médias mais estáveis. Quanto maior n, menor σ/√n, e mais "apertada" fica a distribuição de X̄ em torno de μ.

Essa é a razão pela qual quadruplicar n divide o erro padrão pela metade: √4 = 2 no denominador. Por consequência, divide a margem de erro do IC pela metade. Cortar E pela metade exige quadruplicar n.

Não confunda os três conceitos de "desvio":
σ = dispersão de X individual na população (raramente conhecido).
S = dispersão de X individual na sua amostra (estimativa de σ).
σ/√n = dispersão de X̄ entre diferentes amostras (erro padrão da média).

4. Teorema do Limite Central (TLC)

Pra construir IC, você precisa que X̄ tenha distribuição normal. Caso contrário, a fórmula X̄ ± Z · σ/√n não faz sentido (o Z = 1,96 só funciona dentro da curva normal).

Tem dois caminhos pra garantir que X̄ é normal:

Caminho 1: X já é normal pelo enunciado

Se a variável original X tem distribuição normal (porque o enunciado disse, ou porque você verificou empiricamente), então X̄ é normal pra qualquer n, mesmo n = 5. Sem mistério.

Caminho 2: TLC salva

E quando X não é normal? Pode ser exponencial (tempo de espera), uniforme (sorteio entre 1 e 6), discreta (número de filhos), bimodal, sei lá. Aí entra o TLC:

Se n > 30, então X̄ é aproximadamente normal, independente do formato de X.

Isso é o TLC em uma frase. O TLC age sobre X̄ (a média), não sobre X (o valor individual). Mesmo com TLC, X individual continua com a distribuição original. Mas X̄ vai virando sino conforme n cresce, por uma espécie de "suavização por agregação" (somas e médias de muitas variáveis perdem a forma original e convergem pra normal).

Por isso a régua de bolso é n > 30. Acima disso, a distribuição de X̄ é praticamente normal. Abaixo, sem ajuda do TLC, você precisaria saber que X é normal por outro motivo.

Cenários possíveis:
1. X normal + qualquer n → X̄ normal (sempre dá IC)
2. X qualquer + n > 30 → X̄ normal pelo TLC (dá IC)
3. X não normal + n ≤ 30 → não dá pra concluir, IC inválido

5. IC para média, σ conhecido

Caso mais simples (e o primeiro que se aprende), embora irrealista: o desvio padrão populacional σ é dado no enunciado. A fórmula é:

ICγ% = X̄ ± Zα/2 · σ/√n

Onde:

  • X̄ é a média da sua amostra (centro do IC)
  • σ é o desvio padrão populacional (dado)
  • n é o tamanho da amostra
  • σ/√n é o erro padrão da média
  • Zα/2 é o valor crítico da normal padrão correspondente à confiança escolhida

O Zα/2 sai da tabela:

γα = 1−γα/2Zα/2
90%10%5%1,645
95%5%2,5%1,96
99%1%0,5%2,58

A parte Zα/2 · σ/√n é chamada margem de erro (E). Então o IC pode ser escrito como X̄ ± E, ou [X̄ − E ; X̄ + E].

Zα/2 = INV.NORM.P.N(1 − α/2)
E = INT.CONFIANÇA.NORM(α ; σ ; n) ← atalho, recebe α (não α/2)
LI = X̄ − E
LS = X̄ + E

Exemplo

Tempo de deslocamento no país tem σ = 10 min. Amostra de 200 curitibanos, média 38 min. IC com 95%?

Z = 1,96
E = 1,96 · 10/√200 = 1,96 · 0,7071 = 1,386
IC = [38 − 1,386 ; 38 + 1,386] = [36,61 ; 39,39]
LI = 38 − INT.CONFIANÇA.NORM(0,05 ; 10 ; 200) → 36,61
LS = 38 + INT.CONFIANÇA.NORM(0,05 ; 10 ; 200) → 39,39

6. IC para média, σ desconhecido (a regra S → T)

Na prática, você quase nunca conhece σ. Se conhecesse, provavelmente já saberia μ também (geralmente os dois vêm da mesma fonte populacional), e nem precisaria fazer IC. O caso real é: você tem só S, calculado dos próprios dados da amostra.

A tentação é simplesmente trocar σ por S na fórmula:

IC = X̄ ± Z · S/√n     ← tecnicamente errado

O problema é que isso ignora uma fonte de incerteza. S é uma estimativa de σ, não é σ. Como S tem erro, o IC sai mais estreito do que deveria, e a confiança real fica menor que γ%. Pra compensar esse erro extra, troca-se Z por T:

ICγ% = X̄ ± Tα/2, n−1 · S/√n

O que é a distribuição T de Student

T (T de Student) é uma curva muito parecida com a normal: simétrica, em forma de sino, centrada em 0. A diferença é que ela tem caudas mais pesadas, o que faz com que os valores críticos T sejam maiores que os Z correspondentes. Esses valores maiores compensam o erro de ter estimado σ por S.

T depende de dois números:

  • O nível α/2 (igual no Z)
  • Os graus de liberdade (gl), que pra IC de média sempre é n − 1

Quanto menor n, mais larga a T fica (compensa mais o erro de S, que é maior com pouca amostra). Quanto maior n, mais T se aproxima de Z. No limite n → ∞, T = Z exatamente.

Por que gl = n − 1?

Calcular S amostral exige que você primeiro saiba X̄ (porque a fórmula de S envolve (xᵢ − X̄)²). Você "gasta" um grau de liberdade pra estimar a média antes de calcular o desvio. Sobram n − 1 valores livres pra estimar a dispersão. Não precisa entender a derivação matemática, só lembrar: pra IC de média, gl = n − 1, sempre.

Quando usar T e quando usar Z (com S)

A regra do Nelson: "Se você puser S, ponha T." T sempre é tecnicamente correto, qualquer n. Pra n grande (geralmente n > 50), Z trocando σ por S é uma aproximação aceitável (a diferença com T fica abaixo de 3%), mas T continua sendo a opção rigorosa.

Exemplo

Amostra de 25 funcionários, tempo médio X̄ = 29,6 min, S = 4,62 min. Pop é normal. IC com 97%?

γ = 97% → α = 3% → α/2 = 1,5%

IC = 29,6 ± 2,149 = [27,45 ; 31,75]
E = INT.CONFIANÇA.T(0,03 ; 4,62 ; 25) → 2,149

7. IC para proporção

Quando o que você quer estimar não é uma média, mas uma proporção (% de eleitores do candidato A, % de clientes satisfeitos, taxa de defeito numa linha de produção), a estrutura muda:

ICγ% = p̂ ± Zα/2 · √( p̂(1−p̂) / n )

Onde:

  • p̂ é a proporção amostral (número de "sim" dividido por n)
  • √(p̂(1−p̂)/n) é o erro padrão da proporção, análogo a σ/√n da média
  • Zα/2 é o mesmo valor crítico da normal, sempre Z (não T)

Por que sempre Z, e não T?

Diferente da média, a fórmula do erro padrão de proporção não envolve um parâmetro extra que precise ser estimado e compensado. p̂(1−p̂) já é função só de p̂. Não tem o problema "S em vez de σ" que justificaria usar T. Então sempre Z.

Suposições

Pra a aproximação normal valer, exige-se: n · p̂ ≥ 5 e n · (1−p̂) ≥ 5. Na prática, se p̂ não é extremo (digamos entre 0,1 e 0,9) e n > 30, está garantido.

p̂ = X/n onde X é o número de "sim" e n o total
E = INV.NORM.P.N(1 − α/2) * RAIZ(p̂ * (1 − p̂) / n)
LI = p̂ − E
LS = p̂ + E
Pegadinha "2 pontos percentuais": "candidato A com 30% e margem de 2 pontos" significa E = 0,02, não 2. A gíria de pesquisa eleitoral confunde quem não tá ligado.

Exemplo

Pesquisa com n = 800 eleitores, 240 disseram que votariam no candidato A. IC com 95%?

p̂ = 240/800 = 0,30
Z = 1,96
E = 1,96 · √(0,30 · 0,70 / 800)
  = 1,96 · √(0,000262)
  = 1,96 · 0,01620
  = 0,0318

IC = [0,30 − 0,0318 ; 0,30 + 0,0318] = [0,268 ; 0,332] = [26,8% ; 33,2%]

8. Como interpretar um IC sem cair em pegadinha

Essa é a parte mais cobrada conceitualmente e onde mais gente erra. Existem duas interpretações que parecem iguais em português, mas tecnicamente são diferentes:

Interpretação CORRETA (foca no procedimento):

"Se você refizer o procedimento de coletar amostra e construir IC muitas vezes, γ% dos ICs construídos vão conter o μ verdadeiro." Equivalente: "γ% de probabilidade de o intervalo conter μ."

Interpretação ERRADA (atribui distribuição a μ):

"Tem γ% de chance do μ estar nesse IC específico." O que parece a mesma coisa, mas tecnicamente é errado porque μ é fixo (é um parâmetro populacional, não uma variável aleatória). μ não tem distribuição. Ele está em algum lugar específico, e ponto. A aleatoriedade está no procedimento de construir o IC, não no μ.

Na linguagem do Nelson, dizer "γ% de probabilidade do intervalo conter μ" é aceito (foca no procedimento, no intervalo aleatório). Mas frases que sugerem "μ tem mais chance de estar no centro" ou "μ tem distribuição" são pegadinhas erradas.

Outras pegadinhas comuns

  • "P(X̄ está no IC) = γ%" → ERRADO, é 100%. O IC é construído ao redor de X̄, então X̄ sempre cai no centro por construção.
  • "P(X individual está no IC) = γ%" → ERRADO. O IC é sobre μ, não sobre X. Pra falar de X você precisaria de outra coisa (intervalo de predição, não de confiança).
  • "μ está mais perto do centro do IC com γ%" → ERRADO. Atribui distribuição a μ.
  • "γ% dos indivíduos têm valores no IC" → ERRADO. Mesmo erro que acima.

9. Tamanho de amostra

Pergunta inversa: você quer construir IC com confiança γ e margem de erro máxima E. Quantas pessoas precisa entrevistar?

Inverte a fórmula da margem de erro:

n média (σ conhecido) n = ( Zα/2 · σ / E )²
n proporção (com p̂) n = Zα/2² · p̂(1−p̂) / E²
n proporção (sem estim.) n = Zα/2² · 0,25 / E²

Por que 0,25 quando não tem estimativa

O termo p̂(1−p̂) é maximizado quando p̂ = 0,5, e dá 0,25. Esse é o pior caso (variância máxima da proporção). Usar 0,25 garante a precisão desejada para qualquer p̂ que apareça depois.

Arredondamento

Sempre arredonda pra cima, mesmo que dê 138,01. Isso garante que a margem de erro fica no máximo no E desejado (arredondar pra baixo deixaria E maior que o pedido). Exceção: se o enunciado pedir "arredondamento matemático" explicitamente, aí usa arredondamento normal (5 ou mais sobe).

Trade-off importante

Como n entra na fórmula via 1/√n na margem de erro, a relação é: E ∝ 1/√n. Isso significa que:

  • Quadruplicar n divide E pela metade
  • Cortar E pela metade exige quadruplicar n
  • Cortar E em 1/3 exige multiplicar n por 9

Pesquisa precisa fica cara muito rápido. É um trade-off real que pesa em decisões reais de orçamento de pesquisa.

n média = ARREDONDAR.PARA.CIMA( (INV.NORM.P.N(1−α/2)*σ/E)^2 ; 0 ) n proporção (conservador) = ARREDONDAR.PARA.CIMA( INV.NORM.P.N(1−α/2)^2 * 0,25 / E^2 ; 0 )

Exemplo

Quero estimar o tempo médio de atendimento com margem de 2 min, σ = 17 min, confiança 95%.

Z = 1,96
n = (1,96 · 17 / 2)² = (16,66)² = 277,56
Arredonda pra cima → 278
n = ARREDONDAR.PARA.CIMA( (INV.NORM.P.N(0,975)*17/2)^2 ; 0 ) → 278

10. Suposições — quando o IC vale e quando não

Toda fórmula de IC carrega suposições. Se você aplica sem checar, o resultado pode estar tecnicamente inválido.

Para IC de média

  1. X̄ tem distribuição normal. Isso é o pré-requisito pra Z (ou T) valer. Garantido por: (i) X já é normal pelo enunciado, ou (ii) n > 30 pelo TLC. Se nenhum dos dois, IC inválido.
  2. Amostragem aleatória simples (AAS). Cada elemento da população tem mesma chance de entrar na amostra. Sem AAS, a amostra é viciada e o IC não representa nada.
  3. Se σ é desconhecido, usa S e troca pra T (regra S → T).

Para IC de proporção

  1. n · p̂ ≥ 5 e n · (1 − p̂) ≥ 5. Garante que a aproximação normal da binomial é boa.
  2. AAS, mesmo motivo.
Se a amostra é viciada (ex: só pesquisou amigos, só pegou os que chegaram primeiro, só clientes que reclamaram), nenhuma fórmula salva. O IC vai gerar números, mas eles não representam a população. AAS é hipótese técnica não negociável.

11. Roteiro mecânico antes de cada questão

  1. Identifica o tipo. Proporção? Média? Tamanho de amostra? Conceitual?
  2. Lista o que tem. n, X̄ (ou p̂), σ (ou S), γ, E. O que falta?
  3. Decide Z ou T. Tem σ → Z. Tem só S → T (obrigatório se n ≤ 50).
  4. Checa X̄ normal. X é normal pelo enunciado? Ou n > 30? Senão, IC inválido.
  5. Calcula α/2 e busca Z ou T. Tabela mental ou Excel.
  6. Erro padrão. σ/√n, S/√n, ou √(p̂(1−p̂)/n).
  7. E = Z (ou T) · erro padrão.
  8. IC = estimativa ± E.
  9. Se pediu n: inverte a fórmula, arredonda pra cima.
  10. Vincula células no Excel. Nunca arredonda no meio do cálculo. Arredonda só no resultado final.
