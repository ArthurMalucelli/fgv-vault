2. Fórmulas-mãe

IC média, σ conhecido   IC = X̄ ± Zα/2 · σ/√n
IC média, σ desconhecido   IC = X̄ ± Tα/2, n−1 · S/√n
IC proporção   IC = p̂ ± Zα/2 · √( p̂(1−p̂) / n )
n média   n = ( Zα/2 · σ / E )²
n proporção (conserv.)   n = Zα/2² · 0,25 / E²
n proporção (com p̂)   n = Zα/2² · p̂(1−p̂) / E²

3. Z ou T? Quando usar + como buscar no Excel

SituaçãoUsaFórmula Excel
IC para proporção (qualquer caso)Z=INV.NORM.P.N(1 − α/2)
IC para média, σ DADO no enunciadoZ=INV.NORM.P.N(1 − α/2)
IC para média, σ desconhecido (só tem S), n ≤ 50T obrigatório=INV.T(1 − α/2 ; n − 1)
IC para média, σ desconhecido, n > 50T (ou Z aprox.)=INV.T(1 − α/2 ; n − 1)
Regra do Nelson: "Se puser S, ponha T." T sempre é tecnicamente correto. Z só usa com σ conhecido ou em proporção. Pra T, sempre gl = n − 1.
Exemplos práticos no Excel

γ = 95% → α/2 = 0,025 → Z = INV.NORM.P.N(0,975)        → 1,96
γ = 90% → α/2 = 0,05  → Z = INV.NORM.P.N(0,95)         → 1,645
γ = 99% → α/2 = 0,005 → Z = INV.NORM.P.N(0,995)        → 2,58

γ = 95%, n = 25 → T = INV.T(0,975 ; 24)                → 2,064
γ = 97%, n = 25 → T = INV.T(0,985 ; 24)                → 2,326
γ = 99%, n = 10 → T = INV.T(0,995 ; 9)                 → 3,250

5. Excel essencial

Zα/2           = INV.NORM.P.N(1 − α/2)
Tα/2, n−1      = INV.T(1 − α/2 ; n−1)
T bicaudal     = INV.T.BC(α ; n−1)

E média σ con. = INT.CONFIANÇA.NORM(α ; σ ; n)
E média σ des. = INT.CONFIANÇA.T(α ; S ; n)

E proporção
 = INV.NORM.P.N(1−α/2) * RAIZ(p̂*(1−p̂)/n)

n média
 = ARREDONDAR.PARA.CIMA(
   (INV.NORM.P.N(1−α/2)*σ/E)^2 ; 0)

γ a partir de Z
 = 2*DIST.NORM.P.N(Z;1) − 1
Atenção: INT.CONFIANÇA.* recebe α (não α/2). Pra γ=95% → α=0,05.

6. Dados crus → X̄ e S

X̄ = MÉDIA(intervalo)
S  = DESVPAD.A(intervalo)     ← amostral (n−1), usa quase sempre
σ  = DESVPAD.P(intervalo)     ← populacional (n)
p̂  = CONT.SE(int; "sim") / CONT.NÚM(int)

8. Tipos de questão (roteiro genérico)

Tipo 1 · IC média σ DADO

E = INT.CONFIANÇA.NORM(α ; σ ; n)
IC = X̄ ± E

Tipo 2 · IC média σ DESCONHECIDO (dados crus)

X̄ = MÉDIA(dados)   S = DESVPAD.A(dados)
E = INT.CONFIANÇA.T(α ; S ; n)
IC = X̄ ± E

Tipo 3 · IC proporção

p̂ = sucessos/n
E = INV.NORM.P.N(1−α/2) * RAIZ(p̂*(1−p̂)/n)
IC = p̂ ± E

Tipo 4 · Tamanho de amostra (média)

n = ARREDONDAR.PARA.CIMA(
    (INV.NORM.P.N(1−α/2)*σ/E)^2 ; 0)

Tipo 5 · Tamanho de amostra (proporção, sem p̂)

n = ARREDONDAR.PARA.CIMA(
    INV.NORM.P.N(1−α/2)^2 * 0,25 / E^2 ; 0)

Tipo 6 · Achar K em IC=[a;K] dado X̄

Simetria do IC: K = 2·X̄ − a. Distratores: n e γ (não precisa).

Tipo 7 · Achar γ dado n, σ, E (inverso)

Z = E*RAIZ(n)/σ
γ = 2*DIST.NORM.P.N(Z;1) − 1

Tipo 8 · Conceitual TLC

Resposta padrão: TLC garante X̄ normal quando n > 30, independente do formato de X. Age sobre X̄, não X.

Tipo 9 · Conceitual interpretação IC

Resposta padrão: γ% de probabilidade de o intervalo conter μ. Foca no procedimento. Distratores atribuem distribuição a μ, ou confundem X̄ com IC, ou X com IC.

Tipo 10 · Escolha Z vs T

σ dado → Z. Só S → T (gl = n−1). "n < 30 não pode T" é falso.

9. Roteiro mecânico antes de cada questão

  1. Tipo: proporção, média, n, ou conceitual?
  2. O que tem: n, X̄ (ou p̂), σ (ou S), γ, E. O que falta?
  3. Z ou T? Tem σ → Z. Só S → T (obrigatório se n ≤ 50).
  4. X̄ normal? X normal pelo enunciado OU n > 30. Senão, IC inválido.
  5. α/2 → busca Z (1,96/1,645/2,58) ou T no Excel.
  6. Erro padrão: σ/√n, S/√n, ou √(p̂(1−p̂)/n).
  7. E = Z (ou T) · erro padrão.
  8. IC = estimativa ± E.
  9. n? Inverte fórmula, isola, arredonda pra cima.
  10. Vincula células no Excel (NÃO arredonda no meio).

10. Erros recorrentes

1. Usar Z em vez de T quando σ é desconhecido (ex: erro 1,44 em vez de 1,81).
2. Confundir α com α/2 nas funções Excel.
3. INT.CONFIANÇA.* recebe α, não α/2.
4. gl = n em vez de n − 1.
5. Esquecer √n no denominador do erro padrão.
6. Tratar "margem de 2 pontos" como E=2 quando é E=0,02.
7. Arredondar no meio do cálculo (perde decimais e detona o resultado).
8. Não arredondar pra cima no tamanho de amostra (138,01 → 139, não 138).
9. Confundir μ (fixo) com X̄ (aleatório) em questões conceituais.
10. Nome estranho de distribuição (Kinsey, etc.) é distrator: se n > 30, TLC vale.

11. Regra do Nelson

"Se você puser S, ponha T." T sempre é tecnicamente correto, qualquer n. Z só vale com σ conhecido (ou n > 50 como aproximação).
