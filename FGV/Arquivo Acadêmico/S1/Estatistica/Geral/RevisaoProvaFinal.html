Parte I · Distribuição Normal (o motor de tudo)

1. A fdp e a ideia de área = probabilidade

Uma variável aleatória contínua (tempo, peso, demanda, nota) assume infinitos valores num intervalo. Não dá pra listar P(X=x) ponto a ponto, então a probabilidade é descrita por uma função densidade de probabilidade (fdp), a curva. A probabilidade é a área embaixo da curva num intervalo, não a altura da curva.

  • P(X = c) = 0 sempre, num contínuo. Um ponto tem largura zero, logo área zero.
  • Por isso P(a < X < b) = P(a ≤ X ≤ b): o sinal de igual não muda nada, o ponto não soma área.
  • Área total embaixo da fdp = 1 (a variável assume algum valor com certeza).

A Normal (ou curva de Gauss) é a fdp em forma de sino simétrico. Fica definida por dois parâmetros: a média μ (onde está o pico, o centro) e o desvio padrão σ (a largura do sino). Maior σ, sino mais espalhado e mais baixo. Notação: X ~ N(μ, σ²). Atenção, dentro do parêntese costuma vir a variância σ², não o desvio.

2. Z score e a regra empírica

O Z score (padronização) converte qualquer Normal na Normal padrão Z ~ N(0, 1), de média 0 e desvio 1. Ele mede a quantos desvios padrão o valor está da média:

Z = (X − μ) / σ

Z positivo está à direita da média, Z negativo à esquerda, Z = 0 é a própria média. Z é adimensional: um Z = 1,5 significa "1,5 desvios acima da média", seja a variável tempo, peso ou nota. Isso permite usar uma referência única para qualquer Normal.

A regra empírica (decorar) descreve quanta área cai perto da média:

IntervaloÁrea aproximada
μ ± 1σ≈ 68%
μ ± 2σ (mais exato 1,96σ)≈ 95%
μ ± 3σ≈ 99,7%

É daqui que sai o famoso "Z = 1,96 cobre 95% central". Fora de μ ± 3σ quase não sobra área, por isso eventos a muitos desvios da média são raríssimos.

3. Calcular área no Excel

A função entrega sempre a área acumulada à esquerda, ou seja P(X ≤ a). O quarto argumento 1 (ou VERDADEIRO) pede a acumulada. Atenção máxima: o terceiro argumento é o desvio padrão σ, não a variância.

P(X < a) = DIST.NORM.N(a ; μ ; σ ; 1)
P(X > a) = 1 − DIST.NORM.N(a ; μ ; σ ; 1)
P(a < X < b) = DIST.NORM.N(b ; μ ; σ ; 1) − DIST.NORM.N(a ; μ ; σ ; 1)

Normal padrão (Z): P(Z < z) = DIST.NORM.P.N(z ; 1)

Estratégia visual que nunca falha: desenhe o sino, marque a média no centro, sombreie a região pedida. Se a região pedida está à direita, lembre que a função dá a esquerda, então faz 1 menos. Se é uma faixa central, é a área até b menos a área até a.

Variância vs desvio: se o enunciado diz "variância 144", o Excel quer σ = √144 = 12. Tirar a raiz antes. Erro clássico é passar 144 onde devia ir 12.

4. Problema inverso: da área para o valor

O outro tipo de questão dá a probabilidade (a área) e pede o valor de X que a delimita. É o caso de "nota de corte", "quanto produzir", "qual o limite". Usa-se a função inversa, que recebe a probabilidade acumulada à esquerda e devolve o valor.

valor = INV.NORM.N(p_acumulada ; μ ; σ)
Z crítico (Normal padrão) = INV.NORM.P.N(p_acumulada)
Pegadinha do inverso: a função pede a acumulada à esquerda. Se a pergunta é "valor k tal que P(X > k) = 5%", você passa 0,95, não 0,05. Sempre converta a cauda direita para acumulada esquerda: P(X > k) = 5% significa que 95% está à esquerda de k.

Equivalente manual com Z: ache o Z crítico, depois desfaça a padronização com X = μ + Z·σ.

6. Exercícios resolvidos de Normal

Ex 1 · D ~ N(20, 2²), duração de voo em minutos

P(20 < d < 22):
  = DIST.NORM.N(22;20;2;1) − DIST.NORM.N(20;20;2;1)
  Z de 22 = (22−20)/2 = 1   →  área esq = 0,8413
  Z de 20 = 0              →  área esq = 0,5000
  = 0,8413 − 0,5000 = 0,3413  →  34,13%

P(d = 22):
  = 0   (variável contínua, ponto tem probabilidade zero)

k tal que P(d > k) = 5%:
  P(d > k) = 5%  ⇒  P(d < k) = 95%  ⇒  passa 0,95
  k = INV.NORM.N(0,95 ; 20 ; 2) = 20 + 1,645·2 = 23,29 min

Ex 2 · Notas ~ N(70, 144), os 20% melhores aprovados, qual a nota de corte?

Variância 144  ⇒  σ = √144 = 12
"20% melhores"  ⇒  P(X > corte) = 0,20  ⇒  P(X < corte) = 0,80
corte = INV.NORM.N(0,80 ; 70 ; 12)
Z de 0,80 ≈ 0,8416
corte = 70 + 0,8416·12 = 70 + 10,1 ≈ 80,1

A nota de corte é cerca de 80,1. Quem tira acima disso está no topo de 20%.

Ex 3 · Padaria, demanda ~ N(420, 40)

a) P(demanda > 450):
   = 1 − DIST.NORM.N(450;420;40;1)
   Z = (450−420)/40 = 0,75  →  área esq = 0,7734
   = 1 − 0,7734 = 0,2266  →  22,66%

b) Quantos pães para a probabilidade de FALTAR ser 2%?
   Faltar = demanda passar do estoque k  ⇒  P(demanda > k) = 0,02
   ⇒ P(demanda < k) = 0,98  ⇒ passa 0,98
   k = INV.NORM.N(0,98 ; 420 ; 40) = 420 + 2,054·40 = 502,2
   Arredonda PARA CIMA → 503 pães

Arredonda pra cima porque com 502 a chance de faltar passaria de 2%. Sempre que o arredondamento protege a meta, vai pra cima.

Parte II · Amostragem (da população para a amostra)

7. Distribuição amostral da média

Inferência estatística resolve um problema prático: você quer a média μ de uma população enorme, mas medir todo mundo é inviável. Então mede uma amostra de n elementos e calcula a média amostral X̄ para estimar μ.

ConceitoO que é
Parâmetro populacionalμ, σ², p. Valores reais da população, em geral desconhecidos e fixos.
Estatística amostralX̄, S², p̂. Calculados da amostra, usados para estimar o parâmetro.
Distribuição amostral da médiaA distribuição de X̄ se você repetisse a amostragem infinitas vezes (cada amostra dá um X̄ diferente).

Essa distribuição de X̄ tem três propriedades centrais:

E(X̄) = μ (X̄ é não-viesado, centra na verdade)
Var(X̄) = σ² / n (variância da média cai com n)
DP(X̄) = σ / √n ← erro padrão

O erro padrão σ/√n é o desvio padrão das médias amostrais, ou seja, mede o quanto X̄ varia de amostra para amostra. Como σ/√n < σ, a distribuição de X̄ é mais "magra" que a dos indivíduos: valores extremos individuais se diluem na média. Quanto maior n, menor o erro padrão, e mais X̄ gruda em μ.

Quando X já é Normal, X̄ também é Normal exatamente, para qualquer n: se X ~ N(μ, σ²) então X̄ ~ N(μ, σ²/n).

√n, não n. O erro padrão cai com a raiz de n. Para cortar o erro pela metade, é preciso quadruplicar a amostra. Essa relação volta nos intervalos de confiança.

8. A hierarquia σ vs S vs σ/√n

Três "desvios padrão" que parecem iguais e não são. Confundir é o erro número um da matéria:

SímboloMede a dispersão de…Como obtém
σindivíduos X na populaçãoparâmetro, raramente conhecido
Sindivíduos X dentro de UMA amostracalculado da amostra (denominador n−1)
σ/√nmédias X̄ entre amostras diferenteserro padrão, σ dividido por √n

Regra de leitura do enunciado: se a pergunta é sobre uma observação individual, usa σ. Se é sobre a média de n observações, usa σ/√n. Quem troca um pelo outro erra a questão inteira.

9. Teorema do Limite Central

E quando X não é Normal (tempo de espera exponencial, sorteio uniforme, número de filhos)? Aí entra o TLC:

Se n > 30, então X̄ é aproximadamente Normal, qualquer que seja o formato de X.

Pontos que o Nelson cobra:

  • O TLC age sobre X̄ (a média), não sobre X individual. Mesmo com n grande, X continua com a distribuição original. Só a média vira sino.
  • n > 30 é régua de bolso (convenção), não teorema rigoroso. Acima disso a aproximação é boa o bastante.
  • Os três cenários possíveis:
SituaçãoX̄ é Normal?
X já é Normal + qualquer n (mesmo n = 5)Sim, sempre
X qualquer + n > 30Sim, pelo TLC
X não-Normal + n ≤ 30Não dá pra concluir

Truque soma → média

Quando o enunciado fala da soma de n variáveis (peso total no elevador, tempo total), converta para média dividindo os dois lados por n:

P(X₁ + X₂ + … + Xₙ > k) = P(X̄ > k/n)

Funciona porque dividir os dois lados de uma desigualdade por uma constante positiva não muda a probabilidade. Depois aplica a Normal de X̄.

Não multiplique o peso médio por n (tipo 70 kg × 7 = 490) e trate como fixo. Cada elemento sai independente da distribuição. Tem que usar o truque da média com o erro padrão σ/√n.

10. Exercícios resolvidos de amostragem

Telefonema · T ~ N(8, 2), faixa fixa de 7,8 a 8,2 minutos

Uma chamada:        DP = σ = 2     → Z de ±0,2 = ±0,1  → P ≈ 7,97%
Média de 25:        DP = σ/√25 = 0,4 → Z de ±0,2 = ±0,5  → P ≈ 38,3%

Mesma faixa, distribuição da média muito mais concentrada, probabilidade bem maior. É o efeito do erro padrão.

Elevador · X ~ N(70, 10²), 7 passageiros, capacidade 500 kg

Soma → média:  P(ΣX > 500) = P(X̄ > 500/7 = 71,43)
X̄ ~ N(70 , 10/√7)
P(X̄ > 71,43) = 1 − DIST.NORM.N(71,43 ; 70 ; 10/RAIZ(7) ; 1) ≈ 35,27%

Ligações exponenciais · X ~ Exp(μ = 5 min), com σ = μ = 5

Uma ligação:   P(X > 6) = EXP(−6/5) = 0,3012  →  30,12%
Média de 100:  pelo TLC, X̄ ~ N(5 ; 5/√100 = 0,5)
               P(X̄ > 6) = 1 − DIST.NORM.N(6;5;0,5;1) ≈ 0  (minúsculo)

Cada ligação tem 30% de passar de 6 min, mas a média de 100 quase nunca passa. A média estabiliza.

Parte III · Intervalos de Confiança (estimar com margem)

Em vez de cravar "μ ≈ X̄" (estimativa por ponto, frágil), você dá uma faixa: "μ está em X̄ ± E com γ% de confiança". A estrutura é sempre IC = estimativa ± E. A única coisa que muda entre os casos é como se calcula a margem de erro E.

SímboloO que é
γ (gama)nível de confiança (90%, 95%, 99%)
α1 − γ, a chance do intervalo errar
α/2cada cauda (o IC é bilateral)
Emargem de erro, o "bracinho" de cada lado

11. IC para média, σ conhecido (usa Z)

Caso mais simples e o primeiro que se aprende, embora irrealista (quase nunca se conhece σ de verdade).

ICγ% = X̄ ± Zα/2 · σ/√n
γαα/2Zα/2
90%10%5%1,645
95%5%2,5%1,96
99%1%0,5%2,58
Zα/2 = INV.NORM.P.N(1 − α/2)
E = INT.CONFIANÇA.NORM(α ; σ ; n) ← atalho, recebe α (não α/2)

12. IC para média, σ desconhecido + a distribuição t de Student

O caso real: você não conhece σ, só tem o S calculado da amostra. A tentação é trocar σ por S e seguir com Z, mas isso ignora uma incerteza: S é uma estimativa de σ, tem erro próprio. Para compensar, troca-se Z por T.

ICγ% = X̄ ± T(α/2, n−1) · S/√n

O que é a t de Student

É uma curva parecida com a Normal: simétrica, sino, centrada em 0. A diferença é que tem caudas mais pesadas, então os valores críticos T são maiores que os Z. Esses valores maiores alargam o intervalo e compensam o erro de ter usado S no lugar de σ. A T depende de dois números: o nível α/2 e os graus de liberdade (gl) = n − 1.

Por que gl = n − 1? Para calcular S você precisa antes do X̄ (a fórmula de S usa (xᵢ − X̄)²). Você "gasta" um grau de liberdade estimando a média, sobram n − 1. Não precisa da derivação, só fixar: para IC de média, gl = n − 1, sempre.

Quanto menor n, mais pesada a cauda e maior o T. Conforme n cresce, T encolhe até virar Z. No limite n → ∞, T = Z.

T(α/2, n−1) = INV.T(1 − α/2 ; n − 1) ← cuidado: INV.T com ponto, não INVT
E = INT.CONFIANÇA.T(α ; S ; n) ← atalho, recebe α
Regra do Nelson: "se você puser S, ponha T." T é sempre tecnicamente correto, para qualquer n. Z só se usa com σ conhecido, ou como aproximação aceitável quando n é grande (n > 50).

14. IC para proporção (a amostragem de proporção)

Quando o que se estima não é uma média e sim uma proporção (% de eleitores, taxa de defeito, % de satisfeitos), a estrutura muda. p̂ é a proporção amostral (número de "sim" sobre n).

ICγ% = p̂ ± Zα/2 · √( p̂(1−p̂) / n )

Sempre Z, nunca T. Diferente da média, o erro padrão da proporção √(p̂(1−p̂)/n) não tem um parâmetro extra estimado que precise de compensação. p̂(1−p̂) já é função só de p̂, então não existe o problema "S no lugar de σ" que justificaria a T.

Suposição para a aproximação Normal valer: n·p̂ ≥ 5 e n·(1−p̂) ≥ 5. Na prática, com p̂ não extremo e n > 30, está garantido.

p̂ = sucessos / n
E = INV.NORM.P.N(1 − α/2) * RAIZ( p̂ * (1 − p̂) / n )
LI = p̂ − E    LS = p̂ + E
Pegadinha "2 pontos percentuais": "candidato com 30% e margem de 2 pontos" quer dizer E = 0,02, não 2. A gíria de pesquisa eleitoral derruba quem não presta atenção.

15. Tamanho de amostra

Pergunta inversa: quero confiança γ e margem máxima E, quantas pessoas entrevistar? Inverte a fórmula da margem e isola n.

n média (σ conhecido) n = ( Zα/2 · σ / E )²
n proporção (com p̂) n = Zα/2² · p̂(1−p̂) / E²
n proporção (sem estimar) n = Zα/2² · 0,25 / E²

O 0,25 vem do pior caso: p̂(1−p̂) é máximo quando p̂ = 0,5, e vale 0,25. Usar 0,25 garante a precisão para qualquer proporção que apareça depois (abordagem conservadora).

Sempre arredonda PARA CIMA, mesmo 138,01 vira 139. Arredondar pra baixo deixaria a margem maior que a pedida. n ∝ 1/E²: cortar E pela metade quadruplica n, cortar em 1/3 multiplica n por 9. Pesquisa precisa fica cara rápido.

n média = ARREDONDAR.PARA.CIMA( (INV.NORM.P.N(1−α/2)*σ/E)^2 ; 0 )
n prop (conservador) = ARREDONDAR.PARA.CIMA( INV.NORM.P.N(1−α/2)^2 * 0,25 / E^2 ; 0 )

Parte IV · Conceitual e revisão rápida

17. Como interpretar um IC sem cair na pegadinha

É a parte mais cobrada em conceitual e onde mais gente erra. Duas frases parecem iguais em português e tecnicamente não são.

Interpretação correta (foca no procedimento)

"Se eu repetir o procedimento de coletar amostra e montar o IC muitas vezes, γ% dos intervalos construídos vão conter o μ." Equivalente aceito: "γ% de probabilidade de o intervalo conter μ."

Interpretação errada (atribui distribuição a μ)

"Tem γ% de chance de μ estar nesse IC específico." Parece a mesma coisa, mas é errada: μ é fixo, é um parâmetro, não tem distribuição. Ele está num ponto específico e pronto. A aleatoriedade está no procedimento que gera o intervalo, não no μ.

Na régua do Nelson: dizer "γ% de probabilidade de o intervalo conter μ" é aceito (o intervalo é o aleatório). Frases que dão a μ uma distribuição, ou que dizem "μ está mais perto do centro", são as erradas.

S = DESVPAD.A(intervalo) ← amostral, denominador n−1, usa quase sempre
σ = DESVPAD.P(intervalo) ← populacional, denominador n
n = CONT.NÚM(intervalo)
p̂ = CONT.SE(intervalo;"sim") / CONT.NÚM(intervalo)

20. Roteiro mecânico antes de cada questão

  1. Tipo: é Normal pura (área/valor)? média? proporção? tamanho de amostra? conceitual?
  2. Inventário: o que o enunciado dá? n, X̄ ou p̂, σ ou S, γ, E. O que falta?
  3. Normal pura: pede área → DIST.NORM.N. Pede valor dado área → INV.NORM.N (cuidado, passa acumulada à esquerda).
  4. É média ou proporção? Proporção → sempre Z, fórmula √(p̂(1−p̂)/n).
  5. Média, Z ou T? Tem σ → Z. Só S → T (obrigatório se n ≤ 50, regra "puser S, põe T").
  6. X̄ é normal? X normal pelo enunciado, OU n > 30 pelo TLC. Senão, IC inválido.
  7. α/2 e busca o crítico (Z 1,645/1,96/2,58, ou INV.T).
  8. Erro padrão: σ/√n, S/√n, ou √(p̂(1−p̂)/n).
  9. E = crítico · erro padrão, depois IC = estimativa ± E.
  10. Pediu n? Inverte a fórmula, isola, arredonda PARA CIMA.
  11. No Excel, vincula células e nunca arredonda no meio. Arredonda só no resultado final.
Os 10 erros que mais custam ponto:
1. Passar variância onde o Excel quer desvio (tira a raiz).
2. Esquecer que DIST.NORM.N dá a área à ESQUERDA (cauda direita = 1 menos).
3. No INV.NORM.N, passar a cauda em vez da acumulada (P(X>k)=5% → passa 0,95).
4. Usar σ no lugar de σ/√n quando a pergunta é sobre a média de n.
5. Usar Z quando σ é desconhecido e n é pequeno (era T).
6. gl = n em vez de n − 1.
7. Tratar "margem de 2 pontos" como E = 2 quando é E = 0,02.
8. Não arredondar pra cima o tamanho de amostra.
9. INT.CONFIANÇA.* recebe α, não α/2.
10. Confundir μ (fixo) com X̄ (aleatório) em questão conceitual.
