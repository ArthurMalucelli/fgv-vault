## Conceitos-chave

| Item | O que é |
|---|---|
| [[Tecnologia da Informação (TI)]] | Recursos tecnológicos de uma empresa: hardware, software, sistemas aplicativos, redes e dados. Processa, guarda e transporta informação. |
| [[TIC]] | TI + telecomunicações e internet (videoconferência, e-mail, WhatsApp). |
| [[Sistema de Informação]] | Junção de TI e TIC: pessoas + processos + dados + tecnologia trabalhando juntos. Organiza e interpreta informação para apoiar decisão. Conceito mais amplo que TI sozinha. |
| [[ERP]] | Enterprise Resource Planning, sistema integrado de gestão da empresa. |
| [[CRM]] | Sistema de informação para monitorar e gerir o cliente. |
| [[Sistema de Apoio à Decisão (DSS)]] | Decision Support System, voltado para decisões estratégicas. |
| [[Dado, Informação e Conhecimento]] | Dado é fato bruto isolado; informação é dado com sentido/aplicação; conhecimento é a informação interpretada com experiência humana, o que apoia a decisão. |
| [[Lock-in]] | Aprisionamento do consumidor a um produto/marca por custo de troca (financeiro, de aprendizado ou de fidelidade). |
| [[Big Techs]] | Magnificent Seven: Apple, NVIDIA, Microsoft, Netflix, entre outras. |
| [[Sistemas Ciberfísicos]] | Integram redes digitais ao mundo físico: IoT, IA, robótica, sensores, cloud, edge computing, digital twins, veículos autônomos, sistemas embarcados. Permeiam os três níveis organizacionais. |
| [[Exclusão Digital]] | Quem tem acesso à tecnologia fica mais incluído; quem não tem, mais excluído. |
| [[Technostress]] | Estresse causado pelo uso intenso da tecnologia. |

## Pegadinhas / pontos de prova

- Sistema de informação **reduz** o erro humano, **não elimina**. Se a prova disser "elimina", está errado.
- TI ≠ Sistema de Informação: TI é só a tecnologia (o motor). Sistema de Informação é o conjunto (carro + estrada + motorista): pessoas, processos, dados e tecnologia.
- TIC sozinha, sem os outros elementos, pode isolar em vez de conectar.
- Nenhum elemento (pessoas, processo, dado, tecnologia) gera valor sozinho, só quando associados.
- Dado é bruto e isolado; vira informação quando ganha sentido; vira conhecimento quando é interpretado com experiência humana.
- Os três níveis organizacionais (operacional, apoio à decisão gerencial, estratégico) são permeados pelos sistemas ciberfísicos, que não são um nível à parte.
