## Conceitos-chave

| Item | O que é |
|---|---|
| [[Modelo AIDA]] | Funil: Atenção → Interesse → Desejo → Ação. Atitudes ficam entre desejo e ação. |
| [[Atitudes]] | Opiniões duradouras do consumidor sobre uma categoria (marca, objeto). |
| [[Conjunto evocado]] | Todas as marcas que o consumidor lembra (recall set). |
| [[Conjunto de consideração]] | Subconjunto do evocado que o consumidor considera comprar. |
| Atributos das atitudes | Variáveis que o consumidor avalia sobre a marca/objeto. Têm que ser específicos: "qualidade" sozinho não serve, vira doçura, intensidade, etc. |
| Importância (peso) | Peso que se dá a cada atributo no modelo. |
| [[Pesquisa top of mind]] | Pesquisa de marca/candidato lembrado. Pode ser motivada (com lista) ou não motivada (espontânea). Não motivada é a boa para descobrir consideration set. |
| [[Modelo de Fishbein]] | Conta mental: para cada marca, soma ponderada das notas dos atributos. Marca com maior soma é a escolhida. Modelo compensatório. |
| [[Mapa perceptual]] | Gráfico/visualização da tabela do modelo de Fishbein. |
| Categoria (setor/indústria) | Onde marcas competem. Chocolate fino é categoria **presente**, não chocolate. Por isso Cacau Show compete com Boticário. |
| Elementos de marca | Embalagem, sacola, sofisticação visual. Justifica preço sem reputação. |
| [[Regra compensatória]] | Decisão tipo Fishbein: nota baixa em um atributo é compensada por alta em outro. |
| [[Regra não compensatória]] | Atalhos: comprar o primeiro do Mercado Livre, escolher por circunstância (fila, distância). Próxima aula. |
| [[Prototipagem]] | Materialização da ideia. Vídeo conceito, post, site no Lovable, descrição de evento. |
| [[Teste de protótipo]] | Mostrar o protótipo a 10-15 consumidores e pedir avaliação. Boa prática: dar duas opções pra escolher, não perguntar nota direta. |

## Fórmula

```
Atitude(marca) = Σ (peso_i × nota_i)
```

`peso_i` = importância do atributo i (escala 0-10)
`nota_i` = avaliação da marca no atributo i (escala 0-10)

Marca escolhida = aquela com maior soma.

## Pegadinhas / pontos de prova

- **Qualidade não é atributo de atitude.** Qualidade é adjetivo genérico. Atributo tem que ser específico (doçura, teor alcoólico, amargor). Cuidado se aparecer "qualidade" como atributo direto, pode ser pegadinha.
- **Percepção de qualidade** é diferente de qualidade. Percepção é ranking mental (iPhone > Samsung), e isso pode entrar como atributo.
- **Tamanho de fila / distribuição física não entra no modelo de atitudes.** São condições circunstanciais do ambiente, não atributos da marca.
- **Categoria não é o produto físico.** Chocolate fino é categoria presente. Definir errado a categoria = definir errado os concorrentes.
- **Resposta motivada vs não motivada.** Não motivada (espontânea, aberta) é a que descobre o consideration set real. Pesquisa motivada com lista enviesa.
- **Notas no modelo vêm de pesquisa de mercado com consumidores que efetivamente consumiram a marca.** Nunca de discussão interna entre diretores.
- **Modelo de Fishbein é compensatório.** Próxima aula entra em regras não compensatórias (atalhos, decisão por circunstância). Cuidado para não confundir.
- **Para que serve o modelo na prática:** comunicação direcionada. Se a marca só ganha em um atributo, comunica esse atributo, não tenta competir no resto.
