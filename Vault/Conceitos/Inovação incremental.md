# Inovação incremental

## Definição

Grau de [[Inovação]] que **melhora** algo que já existe. Cliente conhecido, necessidade conhecida, trajetória tecnológica consolidada. Risco baixo, payoff incremental.

## Fórmula / aplicação

Sinais de que é incremental:

- Já se sabe o que o cliente quer.
- Tecnologia base existe.
- Setor é maduro e competitivo.

Exemplos:

- iPhones depois do iPhone original (câmera, bateria, tela).
- Indústria da moda (mexe nas características, base conhecida).
- Setor de beleza (necessidade conhecida).
- Ar-condicionado, geladeira pós-lançamento.
- Uber pós-lançamento (Uber Eats, agendamento, motorista mulher).
