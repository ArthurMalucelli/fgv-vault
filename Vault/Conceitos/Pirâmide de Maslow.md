# Pirâmide de Maslow

## Definição

Hierarquia de necessidades humanas. Usada em gestão pra entender qual necessidade um produto/serviço atende. // preencher: estrutura completa dos 5 níveis (fisiológicas, segurança, sociais, estima, autorrealização).

## Fórmula / aplicação

Aplicação na aula de [[Inovação]]: pra criar inovação que pegue, é preciso entender qual necessidade está sendo atendida. Exemplo: o carro atende a necessidade de **locomoção**. O Uber atende locomoção também, mas com camadas adicionais (conveniência, custo).
