# Assíntota Horizontal

## Definição

Reta horizontal y = L da qual o gráfico se aproxima quando x cresce (ou decresce) sem parar. Descreve o comportamento de longo prazo da função.

## Fórmula / aplicação

```
y = L é assíntota horizontal ⟺ L = lim(x→±∞) f(x)  (L finito)
```

Exemplo da aula: quantidade de computadores em função do tempo tendendo a 50 no longo prazo; o gráfico fica em 49, 49,9, ... sem cravar 50.

## Onde aparece nas aulas

```dataview

FROM [[]]
WHERE contains(file.outlinks, this.file.link)
SORT file.name DESC
```
