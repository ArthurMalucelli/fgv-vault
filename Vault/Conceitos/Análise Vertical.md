# Análise Vertical

## Definição

Técnica de leitura das demonstrações em que cada linha vira percentual de uma base comum: no BP, percentual do Ativo Total; na DRE, percentual da Receita. Também chamada de análise common-size. Elimina o efeito tamanho e expõe a estrutura da empresa, o que permite comparar empresas de portes diferentes e identificar o modelo de negócio pela cara do balanço.

## Fórmula / aplicação

<pre>AV do item = item / base do demonstrativo
Base no BP  = Ativo Total (ou Passivo Total)
Base na DRE = Receita Líquida</pre>

Aplicação central: identificar drivers setoriais. Intangível alto sinaliza concessão, ativos biológicos sinalizam agro, PL fino sinaliza banco, imobilizado grande com dívida longa sinaliza frota ou indústria pesada.
