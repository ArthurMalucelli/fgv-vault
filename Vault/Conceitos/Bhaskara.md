# Bhaskara

## Definição

Fórmula para encontrar as raízes de uma equação quadrática `ax² + bx + c = 0`. O discriminante (delta) determina a natureza das raízes: Δ > 0 dá duas raízes reais distintas, Δ = 0 dá raiz dupla (múltipla), Δ < 0 não tem raiz real.

## Fórmula / aplicação

```
Δ = b² − 4ac
x = (−b ± √Δ) / 2a
ax² + bx + c = a(x − x₁)(x − x₂)   (forma fatorada)
```

Em MA1, usada principalmente para fatorar quadráticas ao resolver limites com [[Forma indeterminada]] 0/0.
