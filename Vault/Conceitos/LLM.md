# LLM

## Definicao

**Large Language Model**. Modelo de IA treinado sobre volumes massivos de texto que aprende padroes de linguagem e gera, classifica ou transforma texto a partir de input do usuario.

## Onde se encaixa

- Faz parte da fase atual da [[Inteligencia Artificial]] (a IA existe desde a Segunda Guerra Mundial, LLMs sao a onda atual, pos-2022).
- E a base tecnica das [[IA Generativa]]s.
- Pode operar via interacao direta com usuario ou como [[Agente de IA|agente autonomo]].

## Exemplos

ChatGPT (OpenAI), Claude (Anthropic), Gemini (Google), Llama (Meta), DeepSeek, Grok. Existe uma "guerra" entre big techs por modelo dominante.

## Aplicacoes em operacoes

- Classificar dados nao estruturados (reviews, tickets, transcricoes) em categorias.
- Resumir documentos longos pra tomada de decisao.
- Gerar codigo / queries pra analytics.
- Operar agentes autonomos pra workflows operacionais.
