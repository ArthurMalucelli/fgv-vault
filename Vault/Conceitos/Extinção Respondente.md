# Extinção Respondente

## Definição

Desaparecimento gradual da resposta condicionada quando o estímulo condicionado é apresentado repetidamente sem o estímulo incondicionado: sino sem carne, dia após dia, até o cão parar de salivar.

## Fórmula / aplicação

```
Sino + carne (emparelhamento) → sino elicia saliva
Sino, sino, sino... sem carne → resposta enfraquece → extinção
```

Descoberta de [[Pavlov]] dentro do [[Condicionamento Clássico]].
