# Função Potencial

## Definição

Função com expoente fixo e base variando: f(x) = xⁿ. Contrasta com a [[Função Exponencial]] (base fixa, expoente variando). As regras de manipulação das duas são totalmente diferentes: não aplicar a de uma na outra.

A professora pediu pra saber, de cada caso, o domínio e o gráfico.

## Fórmula / aplicação

| Caso | Exemplo | Domínio |
|---|---|---|
| n par positivo | x², x⁴ | ℝ |
| n ímpar positivo | x, x³ | ℝ |
| n par negativo | x⁻² = 1/x² | ℝ menos {0} |
| n ímpar negativo | x⁻¹ = 1/x | ℝ menos {0} |
| n racional | x^(1/2) = √x | [0, +∞) |
