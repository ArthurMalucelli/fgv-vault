# Domínio de Função

## Definição

Conjunto de valores de x para os quais f(x) está definida. Varia conforme o tipo de função:

- Potencial, expoente par positivo (x², x⁴): reais
- Potencial, expoente ímpar positivo (x, x³): reais
- Potencial, expoente par negativo (x⁻², x⁻⁴): reais menos o zero
- Potencial, expoente ímpar negativo (x⁻¹, x⁻³): reais menos o zero
- Potencial, expoente racional (raiz, x^(1/2)): reais não-negativos (radicando ≥ 0)

Em função composta com raiz, o domínio é definido pelo que está dentro da raiz: precisa ser ≥ 0.
