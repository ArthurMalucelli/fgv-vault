# Sistema de Informação

## Definição

Junção de [[Tecnologia da Informação (TI)|TI]] e [[TIC]]: conjunto integrado que envolve pessoas, processos, os dados coletados por essas pessoas e a tecnologia, trabalhando juntos para gerar informação que apoia a tomada de decisão. É um conceito mais amplo que a tecnologia sozinha. Nenhum desses elementos gera valor sozinho, só quando associados.

## Fórmula / aplicação

Analogia do carro: TI é o motor, Sistema de Informação é o conjunto do carro, do motor, da estrada e do motorista (as pessoas).

Por que sistemas de informação geram valor:
- Automatizam processos (vendas, estoque, pagamento)
- Fornecem informação para decisões gerenciais
- Integram áreas e departamentos
- Melhoram comunicação e reduzem custos
- Aumentam eficiência
- Reduzem (não eliminam) erro humano
- Geram inovação e vantagem competitiva
- Apoiam a gestão

Estrutura técnica: entrada (dados de fornecedores, clientes, acionistas, concorrentes, órgãos reguladores) → processamento (verificação de estoque, entrega, pagamento) → saída (relatórios, dashboards, indicadores).

Níveis organizacionais: operacional, apoio à decisão gerencial, estratégico — permeados pelos [[Sistemas Ciberfísicos]].
