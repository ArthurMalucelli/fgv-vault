# Limite no Infinito

## Definição

Comportamento de f(x) quando x → +∞ ou x → −∞ (pra onde a função vai "nas pontas" do eixo x). Pra polinômios e quocientes de polinômios, é governado pelo [[Termo de Maior Grau]].

## Fórmula / aplicação

Exemplo da aula (08.13): (6x³ + 4x² + …)/(x² + …) ~ 6x³/x² = 6x, que vai pra +∞ quando x → +∞ e pra −∞ quando x → −∞. Sinal: potência par de x negativo dá positivo, potência ímpar mantém negativo.
