# Lei de Weber

## Definição

A quantidade de mudança necessária pra que uma diferença entre dois estímulos seja notada é **proporcional à intensidade do estímulo original**. Quanto mais intenso o estímulo inicial, maior a mudança necessária pra ser percebida. A menor diferença detectável é o **j.n.d.** (just noticeable difference, limiar diferencial).

## Fórmula / aplicação

```
ΔI / I = k
```

`ΔI` = mudança mínima perceptível
`I` = intensidade do estímulo original
`k` = constante do canal sensorial

Aplicações de marketing:
- Shrinkflation: reduzir quantidade/concentração **abaixo** do j.n.d. pra cortar custo sem o consumidor notar.
- Melhorias de produto e descontos precisam ficar **acima** do j.n.d. pra serem percebidos.
- Redesigns graduais de logo (mudanças abaixo do j.n.d. em cada passo).

Pegadinha de prova: o j.n.d. NÃO é uma constante absoluta, é proporcional ao estímulo base.
