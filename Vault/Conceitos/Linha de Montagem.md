# Linha de Montagem

## Definição

Sistema de produção em que o produto se move pelos operários parados, em vez dos operários irem até o produto. Inventada por Ford na produção do Modelo T.

## Fórmula / aplicação

Caso clássico de [[Inovação de processo]] **radical** ([[Inovação radical]]):

- Antes: operários se deslocavam até o carro pra montá-lo.
- Depois: o carro passava pela linha, cada operário fazendo uma operação fixa.
- Pro consumidor: o carro era o mesmo.
- Pra empresa: muito mais rápido, menos desperdício, menos demora.

Adotada até hoje em todos os setores produtivos.
