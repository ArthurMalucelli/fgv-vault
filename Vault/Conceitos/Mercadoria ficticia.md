# Mercadoria fictícia

## Definição

Coisa que é comerciada **como se fosse** mercadoria, mas que não foi produzida pelo trabalho humano. Pra existir como mercadoria, precisa de uma **invenção sustentada pela força do Estado**.

Conceito vem do [[Polanyi]] (e antes, em raiz, do [[Marx]]). Streeck retoma pra explicar a desregulamentação neoliberal.

## As três mercadorias fictícias

| Mercadoria | Por que é fictícia | Mecanismo de garantia |
|---|---|---|
| **Terra/natureza** | Não foi feita pelo trabalho humano. "Quem fez foi Deus" | [[Propriedade privada]]. Cerca + Estado + monopólio da força |
| **Conhecimento/dinheiro** | Custo de reprodução zero. Papel é só papel sem valor intrínseco | [[Patente]], direito autoral, valor monetário decretado pelo Estado |
| **Trabalho** | Tempo, inteligência, força humana não são produtos. Não é da natureza humana vender o tempo | Disciplina (ética protestante, [[Acumulação primitiva]], [[Foucault]]) + Estado garantindo o mercado de trabalho |

## Por que importa

**Tese central**: o capitalismo só funciona porque essas três mercadorias fictícias são reguladas pelo Estado. Quando o Estado solta o freio (neoliberalismo), a casa cai. Exemplos: [[Crise de 2008]], [[Banco Master]], [[anarquia global]] pós-Trump, crise climática.

> "Um sistema em que a lógica interna de acumulação permanente é infinita, como que esse sistema vai lidar com uma coisa que é finita, chamada mundo? Não tem como."
