# Lucro Bruto

## Definição

Receita líquida menos o custo (CPV/CMV). É o valor agregado da atividade-fim da empresa, antes dos gastos da atividade-meio ([[Despesas Operacionais]]).

## Fórmula / aplicação

```
Lucro bruto = Receita líquida - CPV
```
