# Modelo CAB

## Definição

Toda atitude tem três componentes (também aparece como ABC):
- **C**ognição: crenças, o que o consumidor acredita ser verdade sobre o objeto.
- **A**feto: o que ele sente em relação ao objeto.
- **B** (behavior) / conação: intenção de comportamento, ação.

A **ordem** em que os componentes se formam define a **hierarquia de efeitos**, e é isso que cai em prova.

## Fórmula / aplicação

| Hierarquia | Ordem | Situação típica |
|---|---|---|
| Padrão / aprendizagem (alto envolvimento) | C → A → B (pensar, sentir, fazer) | Pesquisa extensa antes de comprar |
| Baixo envolvimento | B → A → C no deck da professora | Compra com conhecimento mínimo, atitude se forma depois |
| Experiencial (hedônica) | A → B → C (sentir, fazer, pensar) | Consumo emocional |
| Dissonância-atribuição (aparece no quiz) | B → A → C | Impulso → gosta → racionaliza e recomenda |

Regra prática quando "dissonância-atribuição" está nas alternativas: impulso com afeto forte pós-compra = dissonância-atribuição; rotina sem elaboração com atitude fraca só após uso = baixo envolvimento.
