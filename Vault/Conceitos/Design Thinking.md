# Design Thinking

## Definição

Metodologia de inovação centrada no usuário. Cinco estágios iterativos pra desenvolver soluções a partir das necessidades reais do consumidor, não de palpites internos da empresa.

## Os cinco estágios

| Estágio | Ação | Saída |
|---|---|---|
| Empathize | Aprender sobre o público pra quem se desenha | Insights sobre necessidades reais |
| Define | Construir ponto de vista baseado em insights | Problema bem formulado |
| Ideate | Brainstorm de soluções criativas | Lista de ideias |
| Prototype | Construir representações de uma ou mais ideias | Protótipo testável |
| Test | Voltar ao usuário original e testar pra coletar feedback | Iteração ou validação |

Loop: o output de Test alimenta de volta as fases anteriores. Não é linear.
