# Despesa Antecipada

## Definição

Pagamento feito antes de o recurso ser consumido: aluguel pago adiantado, seguro anual, assinatura. No momento do pagamento não é despesa, é ativo (um direito de usar o recurso no futuro). Vira despesa na [[DRE]] mês a mês, conforme o consumo, pelo [[Regime de Competência]]. É o caso em que o caixa sai antes do fato, o inverso de salário ou fornecedor a pagar.

## Fórmula / aplicação

```
Aluguel de 3 meses pago adiantado: 900
No pagamento:  caixa -900 | despesa antecipada +900 (ativo)   -> DRE não muda
Cada mês:      despesa antecipada -300 | despesa de aluguel 300 -> DRE cai 300, caixa não muda

Efeito no FCO do mês do pagamento: -900 inteiro
Efeito no lucro do mês do pagamento: -300 só
```
