# Equação Patrimonial

## Definição

Ativo = Passivo + Patrimônio Líquido. O lado esquerdo do [[Balanço Patrimonial]] (aplicações) é sempre igual ao lado direito (origens) porque não existe aplicação de recurso sem origem correspondente. Serve também como teste de erro: se os dois lados não batem, houve erro de registro.

## Fórmula / aplicação

```
Ativo = Passivo + Patrimônio Líquido
```
