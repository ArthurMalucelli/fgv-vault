# Análise teórica

## Definição

Modalidade de análise em pesquisa cujo objeto é um **texto** (fonte secundária), não um documento (fonte primária). Quando o trabalho usa autores como Catalani ou Streeck como objeto de análise, isso se chama análise teórica.

## Distinção operacional

- Se o objeto é um [[Documento]] (manifesto, programa eleitoral, ato oficial), é análise de documento.
- Se o objeto é um texto interpretativo de outro autor (artigo, ensaio, livro teórico), é análise teórica.

Tem implicação prática no projeto do trabalho final de Soc: o que vai ser declarado como "objeto" determina a metodologia.
