# Resumo — Nature vs Nurture + Pavlov

| Item | O que é |
|---|---|
| [[Nature vs Nurture]] | 2º grande debate da psicologia (o 1º é mente-corpo): genética/herdado vs ambiente/meio |
| 4 aspectos do humano | Afetivo, cognitivo, instintivo, comportamento; cada abordagem foca um e se posiciona no eixo nature-nurture |
| [[Behaviorismo]] | Extremo nurture (100% ambiente): sem essência inata, pessoa = "programa/máquina num ambiente"; nasce nos EUA (Harvard), virada do séc. XX, demanda por disciplina (trabalho, escolas) |
| [[Pragmatismo]] | Verdade = o que serve/funciona ("a verdade só é verdade enquanto função de algo"); descarta o debate metafísico insolúvel |
| [[Tábula Rasa]] | Empirismo: nasce-se em branco ("não nasci X, me tornei X") |
| Objetivismo | Só se estuda o observável (Kant); o objetivo da psicologia = comportamento; pensamento é subjetivo |
| Evolução | Fundamento maior: todo comportamento tem função de sobrevivência/adaptação (consciência existe porque ver o leão era vantajoso) |
| Watson vs [[Skinner]] | Watson: valor histórico. Skinner: valor prático, "está para o behaviorismo como Freud para a psicanálise", carreira em Harvard |
| Comportamento | Interação organismo ↔ ambiente, explicada SEM recorrer ao mental |
| Estímulo / Resposta | Estímulo = mudança no ambiente; resposta = mudança no organismo |
| Aprendizagem | Incorporar comportamento novo ao repertório comportamental (bicicleta) → derruba a "frase dos 7 anos" |
| [[Reflexo Inato]] | Estímulo-resposta que não se aprende nem se controla: bebê × fogo, martelada no joelho, salivação; emoções vêm de fábrica |
| [[Pavlov]] | Fisiologista russo; estudando digestão de cães descobriu POR ACIDENTE a antecipação (salivavam antes da comida) |
| [[Condicionamento Clássico]] | Estímulo neutro (sino) emparelhado com estímulo incondicionado (carne) → após repetição, o neutro sozinho elicia a resposta (reflexo condicionado) |
| [[Extinção Respondente]] | Apresentar o estímulo condicionado repetidamente SEM o incondicionado → a resposta condicionada some |
| Neurose experimental | Excesso de emparelhamentos/estimulação → o organismo "quebra" (prof: não se apegar ao nome) |

## Sequência de Pavlov (cai em prova)

```
1. Sino (neutro) → nada
2. Carne (incondicionado) → saliva (resposta inata)
3. Sino + carne, repetido (emparelhamento)
4. Sino sozinho → saliva (resposta CONDICIONADA)
5. Sino sem carne, repetido → extinção respondente
```

## Caso Goldman Sachs

- Política real: traders proibidos de trabalhar mais de 17h/dia; eles QUERIAM passar disso.
- Excesso de estimulação quebra sapiens como quebrou o cão de Pavlov, mas a motivação humana é mais complexa: dinheiro é reforçador, mas Uber por 17h no mesmo dinheiro ≠ mesmo comportamento; 21h de CS também quebra.

## Pegadinhas / pontos de prova

- Estímulo NEUTRO vira CONDICIONADO após o emparelhamento; incondicionado é o que já elicia resposta inata. Não trocar os nomes.
- Condicionamento clássico é sobre respostas INVOLUNTÁRIAS/reflexas (salivar, medo), não sobre recompensar comportamento voluntário (isso é operante, módulo seguinte).
- A atividade de propor solução via condicionamento clássico: 90% erram exatamente por propor esquema de recompensa (operante) em vez de emparelhamento de estímulos.
- Frase dos 7 anos: atribuição a Aristóteles é incerta; behaviorismo a REJEITA (moldagem contínua pelo ambiente).
