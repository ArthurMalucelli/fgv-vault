# CMV

## Definição

Custo das Mercadorias Vendidas: o custo do que foi efetivamente consumido ou vendido no período, reconhecido na [[DRE]] junto com a receita que gerou ([[Regime de Competência]]). Compra que não foi consumida não é CMV, fica parada como estoque no ativo. Primeira linha de dedução da receita, define o [[Lucro Bruto]].

## Fórmula / aplicação

```
CMV = Estoque inicial + Compras - Estoque final

Caso Zezinho M1: CMV = 0 + (450 + 250) - 0 = 700
(tudo consumido, estoque final zero, então CMV = compras)
```
