# Casa do Lean

## Definicao

Modelo visual que estrutura o [[Pensamento Enxuto]] como uma casa. Usado por Taiichi Ohno na Toyota. No slide do professor (11.05) aparece com a seguinte estrutura.

## Estrutura

**Telhado (objetivos):** Qualidade, Custo, Prazo, Reducao de desperdicios.

**Pilares (2 + envolvimento no centro):**

| Pilar esquerdo | Centro | Pilar direito |
|---|---|---|
| [[Just-in-Time]] | ENVOLVIMENTO | [[Jidoka]] |
| "A peca certa, no tempo certo, na quantidade certa" | Propositos, cultura | "Qualidade construida a partir do processo" |
| Fluxo continuo | | Separacao homem/maquina |
| [[Takt time]] | | Identificacao de anormalidades |
| [[Sistema puxado]] | | [[Poka Yoke]] |
| Mao-de-obra flexivel | | |

**Base (3 elementos sobre estabilidade):** [[Heijunka]], [[Trabalho Padronizado]], [[Kaizen]], sobre **Estabilidade** operacional.

## Como ler

A casa nao fica em pe sem:
- **Base estavel**: sem padrao, nivelamento e melhoria continua, os pilares caem.
- **Os dois pilares**: JIT entrega o fluxo correto na hora certa; Jidoka garante que o defeito nao passa. Um sem o outro produz lixo rapido (so JIT) ou qualidade lenta (so Jidoka).
- **Envolvimento das pessoas**: cultura e proposito sao o que liga os pilares e a base. Lean sem gente engajada nao funciona.
