# Pandas

## Definição

Biblioteca Python para manipulação de dados tabulares. Estrutura central é o [[DataFrame]], análoga a uma planilha. Importada por convenção como `pd`:

```python
import pandas as pd
```

Não está na biblioteca padrão do Python, sempre precisa ser importada. Funções como `print` e `input` já vêm pré-carregadas pelo Jupyter, as do Pandas não.

## Fórmula / aplicação

Faz em Python o que se faz em Excel, mas de maneira programática. Permite fatiar, ordenar, agregar, filtrar logicamente, calcular estatísticas, manipular séries temporais.
