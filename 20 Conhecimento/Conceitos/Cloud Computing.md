# Cloud Computing (computação em nuvem)

## Definição

Entrega de serviços de computação (servidores, armazenamento, banco de dados, redes, software) via internet. Modelo de pagamento por uso, sem comprar infraestrutura física. Um dos [[Sistemas Ciberfísicos]].
