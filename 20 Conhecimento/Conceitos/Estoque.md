# Estoque

## Definição

Mercadoria ou insumo comprado e ainda não consumido nem vendido. É ativo ([[Ativo Circulante|circulante]]) no [[Balanço Patrimonial]], não despesa: comprar é trocar caixa (ou [[Contas a Pagar|contas a pagar]]) por outro ativo. Só vira resultado quando consumido ou vendido, entrando na [[DRE]] como [[CMV]].

## Fórmula / aplicação

```
Estoque final = Estoque inicial + Compras - CMV

Caso Zezinho M2: 0 + 1.340 - 680 = 660
(comprou 1.340, consumiu 680; os 660 ficam no ativo esperando M3)
```
