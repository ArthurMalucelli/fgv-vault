# Assíntota Vertical

## Definição

Reta vertical x = a da qual o gráfico se aproxima indefinidamente. Só pode ocorrer em ponto de restrição do domínio: se a pertence ao domínio, não há assíntota vertical ali.

## Fórmula / aplicação

```
x = a é assíntota vertical ⟺ a fora do domínio ∧ lim(x→a±) f(x) = ±∞
```

Verificar os dois limites laterais. Se o limite dá um número finito, não é assíntota (pode ser descontinuidade removível). Pode haver mais de uma assíntota vertical, uma por restrição de domínio.
