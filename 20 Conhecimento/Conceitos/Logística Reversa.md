# Logística Reversa

## Definição

Processo em que o produto descartado volta pra cadeia produtiva como matéria-prima, em vez de virar resíduo. Fecha o ciclo, transformando lixo em insumo.

## Por que importa

A cadeia tradicional é linear:

```
matéria-prima → extração → produção → comércio → uso → descarte
```

A matéria-prima é finita. Com logística reversa, o descarte volta pro começo:

```
matéria-prima → extração → produção → comércio → uso → descarte
                  ↑                                       |
                  └───────────── reciclagem ─────────────┘
```

Benefício duplo:
1. Evita acúmulo de resíduo no ambiente
2. Evita extração de nova matéria-prima

## Exemplo central: alumínio

Mais de 97% do alumínio usado no Brasil é reciclado. Lata de bebida vira esquadria de janela, corda, qualquer outro produto de alumínio. Brasil é referência mundial nessa cadeia.
