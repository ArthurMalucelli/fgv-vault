# Inbox

Aqui entram arquivos ainda não classificados ou cuja matéria, data ou função não pôde ser determinada com segurança.

A Inbox não é fonte canônica. Depois da triagem, mova cada item para a aula, conceito ou área de sistema correta. O subfolder `Legado` preserva materiais antigos que já existiam antes da reorganização.
