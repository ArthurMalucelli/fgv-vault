# Revisões

Este é o ponto de entrada para revisar o que já foi processado. A fila atual é materializada no dashboard a partir das notas e de [[Tasks]].

## Como usar

- Abra a disciplina abaixo e escolha a aula pelo folder `Aulas/MM.DD`.
- Comece pelo arquivo `Resumo - <tema>.md`.
- Use `Transcrito - <tema>.md` apenas para recuperar contexto ou conferir detalhes.
- Marque lacunas reais com `#duvida` e itens de prova com `#prova`.
